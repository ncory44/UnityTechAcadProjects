Unity Tech Academy Projects

This repository contains Unity projects completed as part of coursework at The Tech Academy. The projects demonstrate core Unity development skills, including physics interactions, input handling, and basic gameplay systems.

Repository Structure

Ball-Motion/ – A simple Unity project showcasing object movement and control.

ScoreAGoalGame/ – A project built around scoring mechanics, tracking collisions and goals.

Getting Started
Prerequisites

Unity Hub

Unity 2021/2022 LTS (recommended for compatibility)

Running a Project

Open Unity Hub.

Add the desired project folder (e.g., Ball-Motion or ScoreAGoalGame).

Open it in Unity.

Press Play in the editor.

Learning Outcomes

Understanding of Unity’s component-based architecture.

Working with C# scripts to handle input and object behavior.

Implementing scoring systems and interactive gameplay mechanics.
